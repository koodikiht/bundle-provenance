# Contributing to `bundle-provenance`

## Technical Invariants

1. **No external runtime dependencies**: Do not add third-party packages to `"dependencies"` in `package.json`. All binary format parsers must use standard `Uint8Array`, `DataView`, and `node:crypto`.
2. **In-memory safety**: Never extract untrusted archive payloads (`.asar`, `.crx`) to disk during inspection. Guard all `UInt32LE` header offsets against integer overflow and buffer truncation.
3. **REUSE 3.2 licensing**: Every source file must start with `SPDX-FileCopyrightText` and `SPDX-License-Identifier: MIT`.

## Generative AI Policy (Code Provenance & Copyright Hygiene)

In compliance with European copyright law and the **NLnet Foundation Generative AI Policy v2.0 (October 2026)**:

- **Human-Authored Artefacts Only**: Contributors may not submit source code, binary parser implementations, test fixtures, or documentation generated by Large Language Models (LLMs) or generative coding assistants.
- **Read-Only Analysis Permitted**: Using automated static analysis or read-only security linters to identify edge cases is permitted, provided all fixes and code are written and understood by the human author.
- **Verification**: Every pull request must include unit tests runnable offline via `bun test`.
